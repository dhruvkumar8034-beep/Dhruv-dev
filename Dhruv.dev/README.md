# Dhruv.dev — Developer Portfolio (Pure Static Web App)

A pixel-perfect, high-performance developer portfolio crafted for **Dhruv.dev**, featuring a modern luxury obsidian aesthetic, interactive physics particle canvas, 3D scroll carousel, and fluid transitions.

---

## ⚡ 100% Pure Static (Zero Node.js Dependencies)

This project is built purely with **HTML5, CSS3, and Vanilla JavaScript**.
- **No Node.js / npm build required**
- **No serverless functions or backend required**
- **Instant deployment** on Vercel, Netlify, GitHub Pages, Cloudflare Pages, or direct file viewing!

---

## 🚀 How to Deploy on Vercel (Instant)

### Method 1: Vercel Dashboard (Drag & Drop)
1. Go to **[vercel.com/new](https://vercel.com/new)**.
2. Drag and drop the `Dhruv.dev` folder (or import via Git).
3. Vercel will automatically detect it as a **Static Site** (Framework Preset: **Other**).
4. Click **Deploy**. Your site will be live globally in ~5 seconds with zero configuration!

### Method 2: GitHub Repository
1. Push the contents of `Dhruv.dev` to a GitHub repository.
   *(Make sure `index.html` is at the root of the repository).*
2. Import the repo in Vercel.
3. Click **Deploy**.

---

## 💻 Local Viewing
Simply double-click `index.html` to open it in any browser (Chrome, Edge, Safari, Firefox). All interactive particles, 3D cards, metrics, and animations work out-of-the-box!
